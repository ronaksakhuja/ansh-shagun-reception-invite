# Dr. Ansh & Shagun, Wedding Reception Invite

One public link, no guest database, no admin, no accounts.

Reception: Saturday 19 December 2026, 7:30 PM onwards, Rajmahal, Barsat Road, Panipat 132103.

Stack: React + Vite + TypeScript. Static site, deploys on Vercel.

Artwork: generated for this invite in blush pink + gold, public/invite/ — floral-tl.png, floral-br.png and palace.png are true transparent PNGs (white background removed, lilies and arch openings preserved). No dome or arch shape: one function only, so the invitation is a clean rectangular ivory card with a double gold border. The family's card image was only used to get the content out of it and is NOT shown on the site. Florals are dedicated per corner, never mirrored. Music: Krishna Bansuri by Alex Morgan, Free Music Archive, CC BY 4.0, public/audio/krishna-bansuri.mp3.

Run locally: `npm install` then `npm run dev`. Build: `npm run build`.
